EXPLAINABLE AI

Visual explanation with Grad-CAM

A heatmap showing image regions that influenced the model's classification.

Understanding the heatmap

Grad-CAM (Gradient-weighted Class Activation Mapping) uses gradients from the model's convolutional layers to create a visual explanation.

Warmer colours generally indicate stronger influence on the model's output.

Cooler colours generally indicate lower relative influence.

Important: The heatmap is not a medical lesion detector. Highlighted areas do not prove the presence or absence of pneumonia.

MODEL ARCHITECTURE

Powered by DenseNet121

ClarityX uses DenseNet121, a convolutional neural network architecture developed for image recognition tasks.

DenseNet connects each layer to subsequent layers through feature reuse. This allows the network to use information learned at different depths of the architecture.

The model uses transfer learning from pretrained image-recognition weights, followed by training and fine-tuning for the two chest X-ray classes.

PRIMARY DATA SOURCE

Chest X-Ray Images (Pneumonia)

Paul Mooney's Kaggle dataset, based on the chest X-ray collection associated with the Kermany et al. research.

View Kaggle dataset →

2 Classification categories
224 × 224 Model input dimensions
NORMAL

Chest X-rays labelled as normal.

PNEUMONIA

Chest X-rays labelled as pneumonia.

Dataset note: The original dataset contains 5,216 training images, 624 test images and 16 validation images. The dataset is imbalanced, with more pneumonia images than normal images.

Additional normal-image data

The project also used normal chest X-ray images selected from the Tuberculosis Chest X-ray dataset. These images were selected from its Normal category.

View additional dataset →

Only the selected Normal images were used from this additional source. This does not mean the model was trained to detect tuberculosis.

MODEL DEVELOPMENT

How the model was trained

A transfer-learning approach was used to adapt a pretrained neural network to chest X-ray classification.

01

Data collection

Chest X-ray images were collected from the selected public Kaggle datasets.

02

Image preprocessing

Images were resized to the required model input dimensions and prepared for deep-learning training.

03

Transfer learning

A pretrained DenseNet121 architecture was adapted to classify Normal and Pneumonia chest X-ray images.

04

Fine-tuning and evaluation

Selected network layers were fine-tuned to improve performance on the target image classification task.

05

Model saving

The trained Keras model was saved and integrated into a Flask web application for image inference.

RESPONSIBLE AI

Important limitations

ClarityX is an educational AI/ML demonstration. It has not been clinically validated and must not be used to diagnose, treat, or rule out pneumonia.

  • The model is trained on selected public datasets and may not generalize to all hospitals, equipment or patient populations.
  • The original Kaggle dataset primarily contains chest X-rays from children aged 1–5 years.
  • Image quality, positioning, contrast and other differences can affect predictions.
  • A Normal result does not guarantee the absence of disease.
  • A Pneumonia result is not a confirmed medical diagnosis.
Always consult a qualified medical professional for interpretation of chest X-rays.
